Что такое x402?

x402 — это открытый протокол, возрождающий HTTP-код 402 Payment Required. Он позволяет ИИ-агентам и программам напрямую оплачивать API, данные или услуги с помощью криптовалют (в основном USDC) без участия человека, подписок и API-ключей .

Принцип работы похож на цифровой торговый автомат: агент стучится за ресурсом, сервер выставляет счет (402), агент его оплачивает и получает доступ — и все это за доли секунды .
 Основные компоненты экосистемы

    Клиент (Покупатель): ИИ-агент или сервис, желающий получить доступ к платному ресурсу. Должен иметь криптокошелек .

    Сервер (Продавец): API или веб-сервис, который требует оплату и проверяет факт транзакции .

    Фасилитатор: Доверенный посредник для проверки подписей и исполнения блокчейн-транзакций, чтобы серверу не приходилось напрямую работать с блокчейном .

    Схемы оплаты:

        exact: Фиксированный перевод точной суммы (например, 0.01 USDC).

        upto: Списание по факту потребления в пределах лимита (pay-as-you-go) .

    Связанные стандарты:

        A2A (Agent-to-Agent): Протокол Google для прямого общения и координации между собой разных агентов .

        EIP-3009: Стандарт Ethereum, позволяющий проводить переводы без оплаты газа (комиссии сети) .

        ERC-8004: Стандарт для цифровой идентификации и репутации агентов в блокчейне .

 Инструменты для разработчиков и готовые SDK

1. Для Python-агентов (на базе CrewAI)
Самый простой способ добавить агенту возможность платить — библиотека crewai-x402 .
python

# pip install crewai-x402
from crewai import Agent, Task, Crew
from crewai_x402 import X402Wallet, X402Tool
import os

# Кошелек с бюджетом в USDC
wallet = X402Wallet(
    private_key=os.environ["WALLET_PRIVATE_KEY"],
    network="eip155:84532",  # Тестовая сеть Base Sepolia
    budget_usd=10.00
)

# Инструмент для оплаты
payment_tool = X402Tool(wallet=wallet, auto_pay=True)

# Агент, умеющий покупать данные
agente_researcher = Agent(
    role='Аналитик',
    goal='Собрать платную аналитику',
    tools=[payment_tool]
)

task = Task(description="Получи данные из https://sandbox.agentrails.io/api/x402/protected/analysis")
Crew(agents=[agente_researcher], tasks=[task]).kickoff()

2. Для TypeScript/JavaScript агентов (Google ADK, A2A)

    a2a-x402: Реализация для прямых платежей между агентами. Позволяет серверу выбрасывать исключение x402PaymentRequiredException, а клиенту — автоматически его обрабатывать .

    x402-fetch / x402-axios: Обертки для стандартных HTTP-запросов, которые перехватывают 402-ю ошибку и проводят платеж .

Пример использования x402-fetch:

javascript

import { wrapFetchWithPayment } from "x402-fetch";
import { privateKeyToAccount } from "viem/accounts";

const account = privateKeyToAccount(process.env.WALLET_PRIVATE_KEY);
// Обычный fetch, который сам платит при встрече с 402 ошибкой
const fetchConPago = wrapFetchWithPayment(fetch, account); 

const respuesta = await fetchConPago("https://api-con-pago.com/datos-premium");

3. Облачные решения для сложных сценариев

    Amazon Bedrock AgentCore: Позволяет создавать серверную часть магазина (Lambda@Edge) и управляемую инфраструктуру для агентов-покупателей с корпоративными политиками лимитов .

    Cloudflare Agents SDK: Предлагает готовые middleware withX402 для серверов и withX402Client для клиентов .

 Пошаговый план интеграции

    Определите роль: Кто вы — покупатель услуг или их продавец?

    Выберите сеть: Для тестов обычно используют base-sepolia (там есть краны бесплатных тестовых USDC), для реальных платежей — base (сеть Base) или eip155:1 (Ethereum Mainnet) .

    Подготовьте кошелек: Сгенерируйте приватный ключ и пополните баланс тестовой или реальной валютой.

    Интегрируйте SDK: Выберите подходящий для вашего фреймворка (Python, JS) или облачной платформы.

    Протестируйте в "песочнице": Используйте публичные тестовые стенды вроде sandbox.agentrails.io для отладки взаимодействия .

 Важные нюансы для новичков

    Готовые решения: Вам не нужно реализовывать протокол с нуля. Практически все взаимодействие сводится к использованию готовых пакетов x402-fetch, crewai-x402 и т.д., которые сами обрабатывают криптографию.

    Где брать документацию: Актуальные спецификации всегда лежат в репозитории coinbase/x402 на GitHub в папке specs/ .

    Газ (комиссия): Платежи в USDC могут требовать наличия нативного токена (ETH) для оплаты газа, но существуют схемы (meta-transactions), убирающие эту проблему
